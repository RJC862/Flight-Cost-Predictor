# Overview
Hello, this is my flight price predictor project. It's an ML model trained on 2026 US flight data/prices to predict the future cost of any domestic flight in the U.S.

# The Dataset
The dataset is from [Kaggle](https://www.kaggle.com/datasets/pooyanayebi/airfare-time-machine-us-flight-prices).

I chose 7 routes to train and test the model on. These 7 have vastly varying features such as distance, popularity, non-stop flights, hub variety.
Routes: MSP-ORD LAS-LAX LAX-IAH LAX-ATL EWR-SFO SEA-LAX BOS-LAX
